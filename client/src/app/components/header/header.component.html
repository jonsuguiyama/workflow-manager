About this project

A Kanban task board demonstrating a full-stack build: Angular Signals for reactive state, Angular CDK drag & drop with backend-persisted ordering, and an Express + PostgreSQL API secured with JWT sessions in HttpOnly cookies.

Sign in with the demo button — no account needed.

Every visitor gets their own private, cloned copy of the board, so feel free to create, edit, reorder, reprioritize, or delete tasks — nothing you do here affects anyone else's session. It's wiped automatically after 24 hours, so explore freely.
